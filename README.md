# Diversão com os amigos

Projeto de seleção de jogos para celular.

## Jogos

- Par ou Ímpar — 1x1
- Jokenpô — 2 a 6 jogadores
- Detetive — 8 a 10 jogadores
- Jogo da Forca — 1 a 4 jogadores
- Stop — 2 a 10 jogadores

## Executar

É necessário ter o Node.js 18 ou superior instalado.

```bash
npm start
